# skillz

How to write skills and run them well.

## Skills

- `write` - write, revise, split or review a skill, using `skill-creator` plus the owner's rules for skills.
- `check` - check work against the skill or skills it followed, from a fresh subagent, and fix every miss before the work is handed on.
- `ask-or-decide` - decide whether to settle a question yourself or ask the owner.

`write` also needs Anthropic's `skill-creator` skill, installed separately.

## Install

```
claude plugin install skillz@bots
```
