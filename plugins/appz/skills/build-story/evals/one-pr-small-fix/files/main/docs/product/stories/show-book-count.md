# Show the book count

## Journey
A reader opens the shelf page and, above the list, sees how many books are on the shelf.

## Scenarios
1. Given an empty shelf, when the reader opens the shelf page, then it shows "0 books".
2. Given a shelf holding Dune, Emma and Ulysses, when the reader opens the shelf page, then it shows "3 books".
3. Given a shelf holding only Dune, when the reader opens the shelf page, then it shows "1 book".
