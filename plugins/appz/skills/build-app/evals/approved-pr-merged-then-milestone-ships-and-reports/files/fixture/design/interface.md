# Pantry list interface (screens)

Screens: design/round-1/screens.html, approved as the app's first design.
- `#list` (design/round-1/screens.html#list): the shared list, oldest item at the top; ticked items crossed out; a box to add an item; a "Clear ticked" control.
- `#add` (design/round-1/screens.html#add): typing an item and saving it puts it at the bottom of the list.
- `#cleared` (design/round-1/screens.html#cleared): the list after clearing, ticked items gone.
- The list lives on the app's server, so every phone and laptop sees the same list.
