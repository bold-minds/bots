# Linkshelf requirements (draft)

R1. A person can save a link with one command, with an optional note and tags. (Ines, 2026-03-02 09:21)
R2. A person can list saved links, newest first, and filter by tag. (Ines, 2026-03-02 09:30)
R3. A person can add a tag to a saved link. (Ines, 2026-03-02 09:30)
R4. All data stays on the person's machine; nothing is sent over the network. (Tomas, 2026-03-04 16:05)
