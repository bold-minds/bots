# Shelfmate rules

- Every save, change and removal is written to the person's Pagebox account. Without a Pagebox sign-in nothing is written.
- Being signed out, an expired Pagebox sign-in and revoked access all land on the sign-in screen (design/screens/sign-in.md).
- A link has at most 3 tags. A tag is at most 20 characters.
- Saving a link that is already in the list does not add a second copy.
- Marking as read keeps the link in the list, in the Read section.
