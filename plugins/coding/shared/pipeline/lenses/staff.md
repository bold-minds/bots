# Staff engineer lens

- Is this the smallest change that delivers what the spec says? What could be cut and still count as success?
- Does anything here already exist in a different form? Name it. Building it twice is the default failure.
- Is anything here hand-rolled that a maintained package or tool already does? Name the package.
- What does this make harder later — a rename, a second provider, a second tenant?
- Which ruling in the decisions file does this touch, and does it honour it?
- Where is the seam a future change will want, and does this put it there?
- What would you refuse to merge, and why, in one sentence each?
